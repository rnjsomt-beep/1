# 거래량↑ · 주가 횡보 스캐너

미국 섹터별 시가총액 상위 5종목 중 **거래량은 늘었는데 주가는 횡보 중인 종목**을 찾는 웹 도구입니다.
먼저 **백테스트**로 이 패턴이 과거에 상승으로 이어졌는지 확인한 뒤, 같은 조건으로 **현재 데이터**를 스캔합니다.

## 실행

```bash
pip install -r requirements.txt
python app.py            # http://127.0.0.1:5000 접속
python app.py --demo     # 인터넷 없이 합성 데이터로 화면/기능 확인
```

데이터는 yfinance(Yahoo Finance) 일봉(수정주가)을 사용하며 1시간 동안 메모리에 캐시됩니다.

## 사용 순서

1. **패턴 조건** 설정 (기본값: 20일 횡보, 박스 폭 ≤10%, 순변화 ≤±4%, 거래량 ≥1.3배, 이후 20일 내 +5% 상승이면 성공)
2. **① 백테스트** 탭
   - 종목 입력 → `백테스트 실행`: 종목별 신호 횟수, 승률, 무조건 승률(아무 날이나 샀을 때) 대비 우위, 평균 상승률
   - "횡보 후 상승에 성공한 사례 목록"에서 실제 사례(횡보 시작일, 신호일, 이후 최고 상승률, 박스 돌파 여부) 확인
   - `조건 최적화`: 횡보기간 × 박스폭 × 거래량배수 그리드를 탐색해 승률 하한(Wilson) 기준으로 좋은 조건 상위 15개 표시. 행을 클릭하면 그 조건으로 적용·재실행
   - **선별 종목** = 신호 2회 이상, 승률 50% 이상이며 무조건 승률보다 높은 종목 → `현재 스캔에 추가` 가능
3. **② 현재 스캔** 탭
   - 11개 GICS 섹터 × 시총 상위 5종목(입력란에서 직접 수정 가능). `시총 기준 상위 5 갱신`을 누르면 후보군의 실시간 시가총액으로 다시 선정
   - 현재 조건 충족 여부, 충족 지속 일수, 근접도(조건 충족 정도), 종목별 과거 승률을 함께 표시
   - 아무 행이나 클릭하면 종가·거래량 차트에 과거 신호(성공/실패/진행 중)와 조건 충족 구간이 표시됨

## 패턴 정의

기준일 t에 대해:

| 항목 | 정의 |
|---|---|
| 횡보 | 최근 N일 종가의 (최고 − 최저) / 평균 ≤ 박스 폭 상한, 그리고 N일 전 대비 종가 변화율 ≤ ±순변화 상한 |
| 거래량 증가 | 최근 N일 평균 거래량 ÷ 그 직전 기준기간(기본 60일) 평균 거래량 ≥ 배수 |
| 성공 | 신호 다음 날부터 관찰 기간(기본 20일) 내 최고 종가가 신호일 종가 대비 성공 기준(기본 +5%) 이상 |

연속으로 신호가 나는 경우 첫날만 진입으로 보고, 이후 관찰 기간 동안은 중복 신호를 무시합니다.

## 파일 구성

- `screener.py` — 지표 계산, 신호 추출, 백테스트/최적화/스캔 엔진, 섹터 후보 목록
- `app.py` — Flask 서버 및 JSON API
- `templates/index.html` — 웹 화면 (Chart.js)

> 투자 판단 보조용 도구이며 수익을 보장하지 않습니다. 백테스트 결과는 과거 데이터 기준이며 거래비용·슬리피지는 반영하지 않았습니다.
